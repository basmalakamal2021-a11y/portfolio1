# Basmala Kamal — Portfolio Website

A responsive, single-page portfolio built with HTML and CSS.

## Preview locally
Open `index.html` in a browser. Keep `profile.jpg` in the same folder.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `basmala-portfolio`).
2. Upload `index.html` and `profile.jpg` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish your site.

## Before publishing
- Confirm the contact details and LinkedIn URL.
- Add your actual GitHub profile URL if you want the GitHub link to point to your account.
- Add links to project repositories or screenshots if available.
